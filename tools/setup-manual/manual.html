Every PC and phone

1

Open Settings

Every set-up tool for this device is on one page.

Sign in to the queue as usual. In the menu on the left, under Account, click Settings. Every role has it.

Green box This device is ready. Nothing to do.
Amber box Something is still to do. The box says what, and the button under it starts it.

On a phone the menu is folded away: tap the menu button at the top left to open it.

2

Install the certificate

Once per device, so the secure address opens with no warning.

The queue server makes its own certificate, so each device has to be told once to trust it. Until then the browser shows a warning instead of the queue.

On a Windows PC needs administrator

  1. In Settings, under Install certificate, click Set up this device. The setup page opens and the installer, install-certificate.cmd, starts downloading by itself.
  2. If the browser warns about the file, choose Keep.
  3. Open the file from your downloads. If Windows says Windows protected your PC, click More info, then Run anyway.
  4. Click Yes on the administrator prompt and wait until it says Done.
  5. Restart the browser: type edge://restart in Edge or chrome://restart in Chrome, and press Enter.
  6. Open Settings again on the secure address (https://). The box turns green.

On a phone or tablet

Android In Settings, tap Certificate for a phone to download it. Open the phone's Settings, search for CA certificate, tap Install anyway and pick sheehan-ca.crt. Close Chrome completely and open the queue again.
iPhone / iPad In Safari, tap Certificate for a phone, then Allow. Open Settings → Profile Downloaded → Install. Then Settings → General → About → Certificate Trust Settings and turn on Sheehan QMS local certificate authority.
Is this safe?It only makes the device trust the shop's own queue server. Nothing else on the device changes.
3

Install the app

Sheehan QMS gets its own icon and window, like any program.

Installed, the staff pages open from a Sheehan QMS icon on the desktop and in the Start menu, in their own window with no address bar or tabs. It stays up to date by itself: it's the same site, on the same server.

On a Windows PC

  1. Install the certificate first (part 2). Edge and Chrome only offer Install app on the secure address.
  2. Open the queue in Edge or Chrome and sign in.
  3. In Settings, under Install app, click Install app. The same button is also at the bottom of the menu.
  4. In the browser's window, click Install.
  5. To keep it in the taskbar: right-click its icon there and choose Pin to taskbar.
No Install app button?It only shows in Edge or Chrome, on the secure address, while the app isn't installed yet. Already installed: open Sheehan QMS from the Start menu.
No certificate yet?In Settings, download install-app.cmd, open it, and choose More info → Run anyway. It makes the same icon, over the plain address.

On a phone: in Chrome, open the menu (⋮) and tap Add to home screen. In Safari on an iPhone, tap Share → Add to Home Screen.

4

Set the ticket paper to 5.5 × 8.5 in

Once, on the PC with the ticket printer.

Tickets print on half letter paper, 5.5 × 8.5 in, fed in standing up. The app asks the browser for that size, but the browser can only use sizes the printer has in Windows. If it isn't there, the browser falls back to Letter (8.5 × 11 in) and the ticket comes out cut in half or in the wrong place.

How the paper goes in

Which PC to set up

Step 1 · Create the paper size, if the printer has none needs administrator

Most printers already have it: Statement (5.5 × 8.5 in)Look in the printer's Printing preferences (Step 2) first. If Statement is in its Paper size list, pick it and skip this step.
  1. Press Win + R, type printui /s /t0 and press Enter. Print Server Properties opens on the Forms tab.
  2. Tick Create a new form. If it's greyed out, click Change form settings at the bottom first.
  3. Name it Ticket 5.5x8.5.
  4. Choose English, then type Width 5.50in and Height 8.50in. Set all four margins to 0.00in.
  5. Click Save Form, then Close.

Step 2 · Make it the printer's paper

  1. Open Settings → Bluetooth & devices → Printers & scanners and click the ticket printer.
  2. Click Printing preferences. On a shared printer (A), set it on the PC with the printer under Printer properties → Advanced → Printing Defaults instead, so every PC gets it.
  3. Set Paper size to Statement, or Ticket 5.5x8.5 if you made it. It may be on a Paper, Paper/Quality or Advanced page.
  4. Set Orientation to Portrait: the paper goes in standing up. Click OK.

Step 3 · Restart the browser

Close every Edge or Chrome window, then open the queue again. The browser only reads the printer's paper sizes when it starts.

Step 4 · Print a ticket

  1. On Customer order, press Serve, then Print ticket. The print window opens.
  2. Open More settings. Paper size should already say Statement (or Ticket 5.5x8.5). If it says Letter, pick it once; the browser remembers it for this printer.
  3. Margins: None.
  4. Scale: Default (100%), never Fit to page.
Check the previewIt should say 1 sheet of paper, standing up, with the whole ticket on it, turned on its side.

If something goes wrong

The usual problems and what fixes them.

What you see What to do
The ticket is cut in half The browser printed on Letter, because the printer doesn't have the 5.5 × 8.5 in size, or the paper went in lying across. Feed it standing up, the short side first, and set the paper size to Statement (or Ticket 5.5x8.5), Portrait (part 4).
The print window still says Letter (8.5 × 11) The paper size isn't on this printer yet, or the browser was open while you added it. Do Step 1 and 2 on the right PC (shared or direct), close every browser window, and try again.
Neither Statement nor Ticket 5.5x8.5 is in the printer's list Some printers keep their own list. Use their User Defined or Custom size, 5.5 in wide and 8.5 in long.
The ticket prints small, or in a corner In the print window set Scale to Default and Margins to None.
A blank sheet comes out after the ticket The printer still thinks the paper is Letter. Check its Printing preferences (Step 2).
Your connection isn't private This device doesn't have the certificate yet. Open http://sheehanqms.local/install and do part 2.
No Install app button Use Edge or Chrome, on the https:// address, after the certificate. If it's already installed, open Sheehan QMS from the Start menu instead.
A download link in Settings doesn't open HTTPS isn't set up on the server yet. Message the developers from SheeChat.
Still stuck?Open SheeChat → Message developer and say which PC, which printer, and what the print window shows. A photo of the printed ticket helps.
