Set up this device for the Sheehan queue

Once per device: after this, the queue opens securely with no warning.

Checking this device...

Windows PC
Download the installer
  1. If the browser warns about the file, choose Keep.
  2. Open install-certificate.cmd from your downloads. If Windows says Windows protected your PC, click More info, then Run anyway.
  3. Click Yes on the administrator prompt, and wait until it says Done.
  4. Restart the browser: type edge://restart in Edge, or chrome://restart in Chrome, and press Enter.
  5. Open this page again: it should say the device is set up.
Android phone or tablet
Download the certificate
  1. Open Settings and search for CA certificate, or go to Security, then Encryption & credentials, then Install a certificate.
  2. Choose CA certificate, tap Install anyway, and pick sheehan-ca.crt from your downloads.
  3. Close Chrome completely and open this page again.
iPhone or iPad
Download the certificate
  1. Open this page in Safari, tap the button above, then Allow.
  2. Open Settings, tap Profile Downloaded, then Install.
  3. Go to Settings, then General, then About, then Certificate Trust Settings, and turn on Sheehan QMS local certificate authority.
  4. Open this page again.

This only makes the device trust the shop's own queue server. Nothing else is changed.
